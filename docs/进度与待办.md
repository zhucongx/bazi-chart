# 进度与待办

## 待办候选

按用处从大到小排。做之前先问用户要哪一项。

1. **把选中的流月、流日也放进细盘。** 现在细盘前两列只有流年和大运。加上之后是八柱并排，某一天的全部干支一眼能看全。手机上要想好怎么排。
2. **出生地直接选城市。** 现在要自己查经度再填。做成选城市，需要一张城市经度表，表的来源要能核对。
3. **日主强弱的推算面板。** 把得令、得地、得势逐项列出来，看结论是怎么得出的。等配套课程讲到旺衰之后再做。面板里要写明各派的权重不一样，结论只是其中一种算法的结果。
4. **月令司令、调候用神、十干意象。** 这三样现在只能手写在个人数据里。要做成通用的，先得各选定一个出处，把整张表录下来并写脚本核对。出处的情况见 `docs/取法约定.md` 的最后一节。
5. **大运、流年的神煞。** 用处不大：神煞只是标签，各家口诀不一。
6. **其他时区和夏令时。** 现在出生时间只能按北京时间填，夏令时靠手工勾选。
