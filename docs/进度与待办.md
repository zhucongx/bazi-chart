# 进度与待办

## 待办候选

按用处从大到小排。做之前先问用户要哪一项。

1. **把选中的流月、流日也放进细盘。** 现在细盘前两列只有流年和大运。加上之后是八柱并排，某一天的全部干支一眼能看全。手机上要想好怎么排。
2. **出生地直接选城市。** 现在要自己查经度再填。做成选城市，需要一张城市经度表，表的来源要能核对。
3. **日主强弱的推算面板。** 把得令、得地、得势逐项列出来，看结论是怎么得出的。面板里要写明各派的权重不一样，结论只是其中一种算法的结果。「得令、得地、得势」这三个词的出处还没有核对过，做之前要先找到能核对的原文。
4. **格局的后几步。** 现在「格局参考」只走到归类。《子平真诠》后面还有三步：地支会合让用神变化，成格和败格，相神。原文在 `docs/取法约定.md` 里记的那个本子上都有，可以接着做，每一步照样引原文。
5. **月令司令。** 各书不一致，要先选定一种分法。出处的情况见 `docs/取法约定.md`。
6. **国印贵人和披麻的去留。** 这两条口诀没有找到典籍出处。可以拿掉，也可以接着找别的书。
7. **大运、流年的神煞。** 用处不大：神煞只是标签，各家口诀不一。
8. **其他时区和夏令时。** 现在出生时间只能按北京时间填，夏令时靠手工勾选。
9. **更多示例人物。** 现在有康熙帝、曾国藩、孙中山三位。乾隆帝的出生时辰传为子时，但没有查到《清实录》的原文，暂时没放。示例里还没有女性：查过慈禧太后和秋瑾，前者没有查到时辰的记载，后者的生年和生地有几种互相矛盾的说法。加人的条件是已经去世、1645 年以后出生、出生时辰有查得到的出处。
