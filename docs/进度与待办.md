# 进度与待办

## 待办候选

按用处从大到小排。做之前先问用户要哪一项。

1. **出生地直接选城市。** 现在要自己查经度再填。做成选城市，需要一张城市经度表，表的来源要能核对。
2. **日主强弱的推算面板。** 把依据逐项列出来，看结论是怎么得出的。《千里命稿》的「强弱篇」把身强、身弱的构成分条列了（月令旺相、多帮扶等），可以照它做；面板里要写明各派的权重不一样，结论只是其中一种算法的结果。
3. **格局的后几步。** 现在「格局参考」只走到归类。《子平真诠》后面还有三步：地支会合让用神变化，成格和败格，相神。原文在 `docs/取法约定.md` 里记的本子上都有，可以接着做，每一步照样引原文。
4. **月令司令。** 各书不一致，要先选定一种分法。出处的情况见 `docs/取法约定.md`。
5. **五条只有现代出处的神煞的去留。** 天医、披麻、十灵日、六秀日、童子煞在典籍里没有找到口诀。可以拿掉，也可以接着找别的书（问真的学习课堂里还有《星平会海》《五行精纪》等）。
6. **拿问真的本子把其余几部书的引文再对一遍。** 《子平真诠》已经对过。《渊海子平》《穷通宝鉴》《三命通会》《滴天髓》《神峰通考》在问真的学习课堂里也有录文，可以当第二个本子。
7. **其他时区和夏令时。** 现在出生时间只能按北京时间填，夏令时靠手工勾选。
8. **更多示例人物。** 现在有康熙帝、曾国藩、孙中山三位。乾隆帝的出生时辰传为子时，但没有查到《清实录》的原文，暂时没放。示例里还没有女性：查过慈禧太后和秋瑾，前者没有查到时辰的记载，后者的生年和生地有几种互相矛盾的说法。加人的条件是已经去世、1645 年以后出生、出生时辰有查得到的出处。
