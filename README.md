# 八字命盘页面

一个打开就能用的网页：填上出生时间，排出八字命盘，并且解释盘上每一格是怎么推出来的。配合学习八字理论用。

在线地址：<https://zhucongx.github.io/bazi-chart/>

八字是一套传统的符号推演体系，没有可靠证据表明它能预测人生。页面上的解读讲的是这套体系内部怎么推演，不做预测。

## 怎么用

- 页面自带三位名人作示例：黄仁勋、孙宇晨、蒋介石。点顶部信息里的「公历」可以看到出生时间的出处。蒋介石的时辰出自年表；黄仁勋和孙宇晨的时辰没有公开的记录，用的是网上流传的说法，时柱不一定对。页面对他们只排盘、讲干支结构，不作评价。
- 点顶部的「＋ 添加」，填上称呼、性别、出生日期和时间，出生地从列表里选城市（经度会自动填上），保存之后就是一张新的盘。只知道时辰的，可以只选时辰。可以添加多个人，在顶部切换。
- 填的内容只保存在你自己的浏览器里，不会上传到任何地方。换一个浏览器或清空浏览器数据之后就没有了，所以表单里有「导出」和「导入文件」，可以把添加的人存成文件、再读回来。
- 标题里四柱下面标着年柱、月柱、日柱、时柱，日柱的天干上面标着「日主」。往下是两张带标签的卡片，点标签换页。上面一张讲出生时的四柱：日主、五行、十神、六亲、宫位、用神。下面一张跟着大运流年走：四柱细盘、干支关系、根和透、大运流年。照标签从左到右的顺序读就行。
- 先在「大运 · 流年 · 流月 · 流日」四行里选，下面那张卡片的四页都跟着变：前三页把选中的四层排在前四列，和出生时的四柱并排。四柱细盘里每一列都有十神、藏干、十二长生、空亡、纳音和神煞。
- 「日主」一页最上面是四项：日主属性、阴阳参考、旺衰参考、格局参考。后两项各是一句话，详细的在「用神」一页。
- 「五行」一页并排三种数法：五行个数只数盘面的八个字，含藏干数连地支里藏的天干一起数，五行能量照一种公开的计分法把个数换成分数，点分数可以看它是怎么加出来的。这是一家的算法，分值没有典籍出处，页面不拿它定喜用神。
- 「十神」一页里五种关系后面写着合称（比劫、食伤、财才、官杀、印绶），每个十神后面写着它出现几次；「六亲」一页列出每一位亲属看哪个十神、这个十神在盘里的什么位置。
- 「干支关系」在电脑上是一张图：八柱横排，相邻的字之间标着谁生谁克，有合、冲、刑、害的字用线连起来，线上的名字可以点。图里只有五行带颜色，相合和相生是实线，冲刑害破克是虚线。手机上是一排小签。
- 「根和透」是一张表：每个天干在哪些地支里有根，地支里藏的字哪些透到了天干上。
- 「大运流年」把五行能量的分值用到大运、流年上，有图有表：横条是从出生时的四柱累计到选中的每一层，柱子是八步大运和这步大运里每一年各自带来的分数，点柱子可以换大运、换年份。它只记力量的账，不给哪一年打好坏的分。
- 「宫位」按年、月、日、时四柱各列一栏：配谁，里面有哪些十神，和别的柱有什么关系，在五行能量里占几分。只列位置和关系，不写断语。
- 各家入手的地方不同，「用神」一页里各家各占一行：强弱有两行，一行照《千里命稿》，一行照五行能量的分数；最后一行「三行对照」把强弱、格局、调候落在哪些字上摆在一起。页面不把几家合成一个结论。
- 细盘里的每一格、带虚线的字、每一条合冲刑害都可以点。点开的那一处会套上一圈蓝框，解释就出现在它旁边。
- 解释里标着「典籍」的段落引的是古书原文，每一句都对着所据的本子核对过。

支持 1900 到 2100 年、按北京时间记录的出生时间。整个网页只有仓库根目录的 `index.html` 这一个文件，下载下来用浏览器直接打开也能用。
