# 八字命盘页面

填上出生时间，排出八字命盘。盘上每一格都能点开，看它是怎么推出来的。配合学习八字理论用。

在线地址：<https://zhucongx.github.io/bazi-chart/>

八字是一套传统的符号推演体系，没有可靠证据表明它能预测人生。页面讲的是这套体系内部怎么推演，不做预测。

## 几点说明

- 自带黄仁勋、孙宇晨、蒋介石三位作示例，只排盘，不评价这几位。黄仁勋和孙宇晨的时辰没有公开的记录，用的是网上流传的说法。
- 自己添加的人只存在你的浏览器里，不会上传。换浏览器或者清空浏览器数据就没了，可以先导出成文件。
- 「分享」生成的链接里带着出生日期和时辰，拿到链接的人都看得到。
- 支持 1900 到 2100 年、按北京时间记录的出生时间。
- 整个页面就是一个 `index.html`，下载下来用浏览器直接打开也能用。
