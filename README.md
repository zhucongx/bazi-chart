# 八字命盘页面

填上出生时间，排出八字命盘。盘上每一格都能点开，看它是怎么推出来的。配合学习八字理论用。

在线地址：<https://zhucongx.github.io/bazi-chart/>

八字是一套传统的符号推演体系，没有可靠证据表明它能预测人生。页面讲的是这套体系内部怎么推演，不做预测。

## 几点说明

- 自带九位公众人物作示例，只排盘，不评价这几位。出生时间的可靠程度不一样，来历都写在页面上：
  - 雍正、蒋介石的时辰有实录、年表的记载；爱因斯坦、乔布斯、奥巴马、伊丽莎白二世的出生时间来自出生证或官方公告。
  - 黄仁勋、孙宇晨、马云的时辰没有公开的记录；马云用的八字和公开的生日对不上。
- 强弱、喜用、用神这类带判断的内容，是拿一种现代的计分配上几本书里的规则算出来的。每一步照的是哪本书、哪些地方是页面自己定的，点开就能看到；换一家的取法，结果会不一样。
- 自己添加的人只存在你的浏览器里，不会上传。换浏览器或者清空浏览器数据就没了，可以先导出成文件。
- 「分享」生成的链接里带着出生日期和时辰，拿到链接的人都看得到。
- 自己添加的人，支持 1900 到 2100 年出生、按北京时间填。只知道时辰、时辰不详，或者手里只有八字，也能排。
- 整个页面就是一个 `index.html`，下载下来用浏览器直接打开也能用。
